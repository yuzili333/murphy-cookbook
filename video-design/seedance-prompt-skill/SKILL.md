# Seedance 2.0 菜谱烹饪类动画视频提示词与故事板设计模板

生成日期：2026-06-02  
适用场景：使用 Seedance 2.0 创作 4-15 秒菜谱、烹饪、食材处理、美食摆盘类动画视频。

## 1. 来源提炼

本文基于 GitHub 精品提示词合集 [awesome-seedance-2-prompts / README_zh.md](https://github.com/yuzili333/awesome-seedance-2-prompts/blob/main/README_zh.md) 归纳。该合集说明 Seedance 2.0 支持文本、图片、视频、音频四模态输入，视频时长覆盖 4-15 秒，最高 1080p；README 本地提取版本显示共有 3587 条提示词、6 条精选提示词，最后更新为 2026-06-01。

与菜谱烹饪最相关的样例有三类：

- 精选三镜头烹饪短片：现代乡村美学、自然光、ASMR、开放式厨房、采摘、切菜、享用。
- storyboard 驱动的炒饭动画：15 秒 16:9 横屏，按分镜顺序完成食材准备、切菜、打蛋、热锅、翻炒、火焰、特写、装盘、成品展示。
- 多帧卡通厨师系列：以逐帧方式描述厨师入场、挑选食材、切菜、翻炒、浇汁、试味、摆盘、揭盖、英雄镜头、美食特写。

归纳出的高质量提示词共同点：

- 先定义风格、画幅、时长、场景、角色，再分镜头描述动作。
- 每个镜头同时写清画面、动作、镜头语言、食物细节、光影和声音。
- 烹饪视频必须强调真实连贯的手部动作、锅具运动、蒸汽、油光、汁水、火焰和食材质感。
- 使用清晰的时间段或帧序号控制结构，避免模型生成静态幻灯片。
- 结尾加入负向约束：无文字、无字幕、无 Logo、无水印、避免手部变形、食材融化、动作不自然、风格不一致。

## 2. 核心提示词公式

```text
[画幅与时长] + [视频类型] + [菜品主题] + [故事板/参考图使用方式] +
[整体风格] + [厨房/餐桌场景] + [角色或手部设定] +
[流程动作] + [镜头设计] + [食物质感] + [光影色调] +
[声音氛围] + [一致性要求] + [负向约束]
```

推荐写法：

```text
根据随附的 storyboard 图像，创作一段 {{duration}} 秒、{{aspect_ratio}} 的 {{video_style}} 菜谱烹饪动画视频。
主题：{{dish_name}}。
严格遵循 storyboard 的分镜顺序，将每一格转化为连续、有节奏的烹饪动作，而不是静态幻灯片。

流程：
{{cooking_flow}}

风格：
{{visual_style}}，电影级布光，高清画质，食物动画表现精致，色彩鲜明但不脏乱。

场景：
{{kitchen_setting}}，保持统一的厨房空间、道具位置、餐具风格和光线方向。

角色/手部：
{{character_or_hands}}。手部动作自然、准确、有重量感，切菜、搅拌、倒入、翻炒、夹取、摆盘动作需要符合真实烹饪逻辑。

镜头：
使用有节奏的快速剪辑，结合俯拍、微距特写、低角度锅边镜头、侧向跟拍、快速平移、匹配剪辑和成品英雄镜头。
在保持菜谱步骤清晰可懂的同时，让画面充满动画张力。

食物质感：
突出 {{food_texture_keywords}}，包括蒸汽、油光、汁水、火焰、米粒/面条/蔬菜的分离度、酱汁流动和成品光泽。

声音氛围：
加入 {{sound_design}}，例如切菜声、油锅滋滋声、火焰声、锅铲碰撞声、轻快音乐或治愈系 ASMR 环境声。

一致性：
全程保持同一厨房氛围、同一动画画风、同一角色外观、同一菜品形态和同一餐具风格。

禁止：
不要生成静态图片 Slides；不要出现文字、字幕、Logo、水印；避免手部变形、食材破碎或融化、锅具漂移、动作不符合物理、镜头间风格突变。
```

## 7. 故事板图片设计思路

### 7.1 网格数量怎么选

| 网格 | 适用场景 | 建议 |
|---|---|---|
| 2x2 / 4 格 | 单一动作展示，如切菜、煎蛋、倒酱、拉丝 | 用于 4-8 秒短视频，动作简单，适合做局部质感测试 |
| 2x3 / 6 格 | 一道菜的简化流程 | 用于 8-12 秒，步骤为食材、切配、下锅、烹饪、装盘、成品 |
| 3x3 / 9 格 | 菜谱动画首选 | 用于 12-15 秒，能完整表达准备、切配、调味、热锅、下锅、爆点、特写、装盘、成品 |
| 2x5 / 10 格 | 角色叙事或卡通厨师系列 | 用于有主角表演、试味、揭盖、英雄镜头的 15 秒视频 |
| 3x4 / 12 格 | 复杂菜品或多段镜头 | 只在需要分两次生成或做详细预演时使用；单条 15 秒视频里格子太多会削弱每步辨识度 |

推荐默认选择：3x3 九宫格。  
原因：15 秒菜谱视频通常需要 8-9 个关键动作，九宫格刚好兼顾流程完整性和画面辨识度。

### 7.2 每格画什么

九宫格推荐结构：

| 格子 | 内容 | 镜头功能 |
|---|---|---|
| 1 | 成品或主食材亮相 | 建立食欲和主题 |
| 2 | 食材准备 | 展示新鲜度 |
| 3 | 切配/清洗 | 展示技艺和节奏 |
| 4 | 调味/打蛋/搅拌 | 展示液体和质感 |
| 5 | 热锅/倒油/起火 | 建立烹饪高潮前奏 |
| 6 | 下锅/翻炒/煎烤 | 主动作爆点 |
| 7 | 食物微距 | 展示油光、蒸汽、拉丝、汁水 |
| 8 | 装盘/撒料 | 完成菜品结构 |
| 9 | 成品英雄镜头 | 用于结尾停留和封面感 |

### 7.3 对标风格怎么选

菜谱动画不建议只写“动画风格”或“高级风格”，要明确对标的视觉机制：

- 治愈自然系：现代乡村厨房、自然光、低饱和木色、浅景深、ASMR、慢动作蒸汽。
- 高能美食番系：高饱和食材、强反光油光、快速剪辑、夸张但可信的火焰、米粒和酱汁动态。
- 卡通厨师系：圆润角色、暖金厨房光、夸张表情、戏剧性揭盖、英雄式成品展示。
- 商业广告系：干净台面、产品级食材摆放、极致微距、精准动作、慢动作汁水和成品推进。

写故事板图片时，每格必须保持同一种风格。不要前几格写实、后几格卡通，也不要混用不同厨房、不同餐具、不同角色脸型。

### 7.4 色调怎么定

推荐调色：

- 主色：暖金、奶油白、木色、米色，用于厨房光和餐桌。
- 食物强调色：番茄红、蛋黄金、葱绿、酱油琥珀、辣椒红，用于提升食欲。
- 对比色：少量青绿色或夜蓝色，用于窗外、阴影或背景，防止画面全黄。
- 火焰与锅气：橙红高光，但面积不要过大，避免压过菜品。

不推荐：

- 全画面单一黄色或橙色，容易显脏。
- 过冷蓝紫厨房，除非主题是夜宵、赛博厨房或反差喜剧。
- 过多霓虹色，会削弱真实食欲。

### 7.5 结构流程怎么安排

菜谱动画的结构不是完整教学，而是“可理解的烹饪爽点压缩”：

```text
开场食欲钩子 -> 食材新鲜感 -> 手艺动作 -> 热锅爆点 -> 食物质感 -> 装盘 -> 成品停留
```

15 秒建议时间分配：

- 0-2 秒：成品/主食材/厨房建立，快速抓住主题。
- 2-5 秒：食材准备和切配。
- 5-8 秒：调味、搅拌、倒入。
- 8-11 秒：下锅、翻炒、火焰、锅气，制造高潮。
- 11-13 秒：微距质感，如拉丝、油光、米粒、汤汁。
- 13-15 秒：装盘和成品英雄镜头。

如果是治愈系，可以改为三段式：

```text
新鲜食材 -> 精准烹饪 -> 安静享用
```

如果是儿童卡通/角色向，可以改为十帧式：

```text
入场 -> 选材 -> 切配 -> 烹饪 -> 加酱 -> 试味 -> 摆盘 -> 揭示 -> 英雄站姿 -> 成品特写
```

### 7.6 镜头设计要点

菜谱动画建议至少覆盖以下镜头：

- 俯拍：展示食材布局、案板动作和步骤清晰度。
- 微距特写：展示刀切、汁水、油泡、米粒、酱汁、拉丝。
- 低角度锅边镜头：展示火焰、颠锅、蒸汽和锅气。
- 侧向跟拍：跟随手部切菜、倒料、滑锅。
- 快速平移：连接食材到锅、锅到盘，增强节奏。
- 匹配剪辑：把“倒蛋液”接“蛋液入锅”，把“翻炒”接“成品装盘”。
- 英雄镜头：成品缓慢推进，最后 1-2 秒停留，适合做封面。

镜头不要全部用特写。至少保留 1 个中景或广角建立厨房空间，否则模型容易让锅具、手部和食物漂移。

## 8. 负向约束清单

每条提示词结尾建议固定加入：

```text
不要做成静态图片幻灯片。无文字、无字幕、无 Logo、无水印。避免手部变形、手指数量错误、刀具穿模、锅具漂移、食材破碎或融化、米粒/面条粘成一团、火焰不符合物理、角色外观漂移、厨房空间跳变、餐具样式不一致、镜头构图混乱。
```

## 9. 示例：黄金蛋炒饭动画

```text
根据随附的 3x3 storyboard 图像，创作一段 15 秒、16:9 横屏的高质量动画烹饪视频。
主题：黄金蛋炒饭。
严格遵循九宫格分镜顺序，将每一格转化为连续、有节奏的烹饪动作，而不是静态幻灯片。

流程：
成品金黄炒饭亮相 -> 葱花、鸡蛋、米饭和胡萝卜丁俯拍 -> 切葱微距 -> 打蛋并搅拌 -> 热锅倒油 -> 蛋液和米饭入锅 -> 颠锅火焰与米粒飞起 -> 撒葱花装盘 -> 成品英雄特写。

风格：
高质量动画电影风格，日式美食动画质感，温暖厨房光，高清，色彩鲜明，食物诱人但画面干净。

镜头：
```

### 10.1 是否在网格内加入关键文字

不建议把分镜关键文字直接放进 storyboard 图片里。原因：

- 视频生成模型可能把图片里的文字当成画面元素延续到视频中，导致字幕、乱码、残留标识或水印感。
- 图像生成模型本身对小字、中文和多格文字排版不稳定，容易出现错误字形，反而干扰画面理解。
- 分镜图的主要价值是锁定视觉顺序、构图、食材状态、镜头角度和风格一致性；文字说明更适合写在 Seedance 2.0 的文本提示词中。

推荐做法：storyboard 图片保持无文字；在配套视频生成提示词中补充分镜说明，例如：

```text
请按 storyboard 从左到右、从上到下理解下方 3x3 网格：
1 食材亮相，2 清洗番茄，3 切番茄和小葱，4 打蛋，5 热锅倒油，6 蛋液入锅，7 加入番茄和调味料，8 翻炒融合，9 成品装盘。
上方横向大图是预备食材和厨房风格参考，不作为独立视频镜头；它用于统一食材、餐具、台面、光线和整体色调。
```

## 11. 制作检查表

- 是否只聚焦一道菜。
- 是否选择了合适网格：默认 3x3，角色叙事可 2x5。
- 是否在网格上方加入预备食材全景图，用来统一食材、厨房、餐具和色调。
- 是否有明确的“食材 -> 烹饪 -> 成品”结构。
- 是否有至少 3 种镜头：俯拍、微距、锅边低角度。
- 是否写了食物质感：蒸汽、油光、汁水、火焰、颗粒感。
- 是否写了声音：切菜、油锅、锅铲、火焰或 ASMR。
- 是否强调不是静态 Slides。
- 是否要求 storyboard 图片内无文字、无字幕、无 Logo、无水印；分镜文字说明放在配套视频生成提示词中。
- 是否限制手部、食材、锅具、厨房和画风的一致性。
