# 儿童烹饪食谱智能体：烹饪步骤视频生成技术方案（即梦 AI 试运行版）

## 1. 评审结论

上一版硅基流动方案已通过真实试跑确认存在关键质量问题：

- `Wan-AI/Wan2.2-I2V-A14B` 单段输出实际约 5 秒，`duration` 参数未形成有效时长控制。
- 人物模型容易失真。
- 字幕容易乱码或不可读。
- 生成视频无稳定声源输出，无法满足“人物对话剧情”要求。

本版先将视频链路切换为火山引擎即梦 AI，并保持应用功能代码完全不改动。试运行目标是验证即梦在“首帧图片 + 1000 字以内提示词 + 15 秒目标时长 + 241 帧图生视频”场景下的视频画面质量和端到端耗时。

重要结论：当前部署目标是 Netlify Functions，不适合承载 TTS/配音与字幕烧录后处理。线上版本先放弃制作 TTS/配音后处理功能，仅生成和缓存即梦返回的原始视频。

本期模型与接口：

- 首帧图片生成：即梦图生图 3.0 智能参考
- 首帧图片接口文档：https://www.volcengine.com/docs/85621/1747301?lang=zh
- 图生视频生成：即梦 AI 视频生成 3.0 720P 图生视频首帧
- 视频接口文档：https://www.volcengine.com/docs/85621/1785204?lang=zh
- 服务域名：`https://visual.volcengineapi.com`
- 提交任务：`Action=CVSync2AsyncSubmitTask&Version=2022-08-31`
- 查询结果：`Action=CVSync2AsyncGetResult&Version=2022-08-31`
- 鉴权固定值：`Region=cn-north-1`，`Service=cv`

核心链路：

```text
RecipeDetail + family.png + 厨房场景 + 菜谱名称
-> 生成首帧图片 prompt
-> 调用即梦图生图 3.0 生成首帧
-> 将烹饪步骤转化为 1000 字以内分镜级视频 prompt
-> 调用即梦图生视频，frames 设置为 241
-> 轮询任务状态
-> 返回 videoUrl / 下载视频文件 / 记录耗时与质量验证结论
```

## 2. 当前项目基础

本期只复用现有数据与本地素材：

- 菜谱名称、食材、烹饪步骤：来自现有 `RecipeDetail`。
- 家庭合照参考图：`video-design/scene/family.png`。
- 厨房场景参考：`video-design/scene/home-kitchen.png`。
- 不修改前端、后端应用功能代码。
- 试运行脚本放在 `/private/tmp`，输出报告也放在 `/private/tmp`。

部署环境评估：

- 当前项目通过 `netlify.toml` 部署为静态前端 + Netlify Functions，服务端入口位于 `apps/server/netlify/functions`。
- Netlify Functions 适合短请求 API，不适合长时间视频转码、字幕烧录、音频合成这类重 CPU/IO 后处理。
- 当前服务端依赖中没有可部署的 TTS 服务、FFmpeg 二进制或对象存储上传链路。
- 本地试运行使用的 macOS `say`、`afconvert`、Homebrew `ffmpeg-full` 不能直接等价迁移到 Netlify Functions。
- 因此线上方案删除 TTS/配音后处理；后续若改为容器化后台任务或专用媒体处理服务，再重新评估字幕与音频能力。

现有 `CookingStep` 不变：

```ts
export interface CookingStep {
  id: string;
  title: string;
  description: string;
  tip: string;
  riskLevel: 'low' | 'medium' | 'high';
  requiresParentAssist: boolean;
  childAction?: string;
  parentAction?: string;
  expectedResult?: string;
}
```

## 4. 即梦接口设计

### 4.1 鉴权配置

真实调用需要本地或部署环境提供：

```text
VOLCENGINE_ACCESS_KEY_ID
VOLCENGINE_SECRET_ACCESS_KEY
```

请求使用火山引擎签名 V4：

```text
Region: cn-north-1
Service: cv
Host: visual.volcengineapi.com
Content-Type: application/json
```

如果缺少鉴权配置，试运行脚本必须直接停止，并在报告中记录：

```text
blocked: missing_volcengine_credentials
```

### 4.2 首帧图片生成

提交任务：

```http
POST https://visual.volcengineapi.com?Action=CVSync2AsyncSubmitTask&Version=2022-08-31
```

请求体：

```json
{
  "req_key": "jimeng_i2i_v30",
  "binary_data_base64": ["<family.png base64>"],
  "prompt": "参考家庭合照中的人物关系与外貌，生成温暖明亮的家庭厨房卡通首帧。画面中爸爸妈妈和小朋友站在厨房操作台前，桌上有番茄、鸡蛋和菜谱名“番茄炒蛋”，人物自然不失真，中文文字清晰。",
  "seed": -1,
  "scale": 0.5
}
```

查询任务：

```http
POST https://visual.volcengineapi.com?Action=CVSync2AsyncGetResult&Version=2022-08-31
```

请求体：

```json
{
  "req_key": "jimeng_i2i_v30",
  "task_id": "<submit task id>",
  "req_json": "{\"return_url\":true,\"logo_info\":{\"add_logo\":false}}"
}
```

成功结果读取：

```text
data.image_urls[0]
```

首帧图片必须先通过 QA 门禁后才能进入视频生成：

- 人物数量必须与剧情设定一致。
- 人物身份必须清晰，例如仅爸爸、妈妈、小朋友三人。
- 如果首帧已经出现额外人物，后续视频 prompt 只能限制“不新增人物”，无法可靠删除首帧中已有角色。
- 若首帧人物数量不符合预期，必须重新生成首帧，而不是继续复用该首帧进入 I2V。

### 4.3 视频生成

提交任务：

```http
POST https://visual.volcengineapi.com?Action=CVSync2AsyncSubmitTask&Version=2022-08-31
```

请求体：

```json
{
  "req_key": "jimeng_i2v_first_v30",
  "image_urls": ["<firstFrameUrl>"],
  "prompt": "<1000 字以内视频提示词>",
  "seed": -1,
  "frames": 241
}
```

`frames` 用于控制视频长度。真实接口已返回约束：`frames` 必须在 `[73, 289]` 范围内。按 24fps 估算：

```text
121 frames ≈ 5 秒
241 frames ≈ 10 秒
289 frames ≈ 12 秒
```

本期按产品要求默认使用 `241`，并在 prompt 中写明“15 秒儿童亲子烹饪教学短片”。接口实际输出仍以帧数为准，真实验证结果可能接近 `241 / 24 ≈ 10 秒`。若后续必须稳定达到 15 秒，需要提高帧数或改为多段视频生成与合成，不能单次调用突破接口帧数上限。

查询任务：

```json
{
  "req_key": "jimeng_i2v_first_v30",
  "task_id": "<submit task id>",
  "req_json": "{\"return_url\":true,\"logo_info\":{\"add_logo\":false}}"
}
```

成功结果读取：

```text
data.video_url
```

## 5. Prompt 设计

即梦视频 Prompt 默认使用中文，最长控制在 1000 字以内。完整烹饪步骤需转化为分镜级连续动作，而不是只做步骤摘要：

```text
清洗番茄 -> 打散鸡蛋 -> 家长协助切番茄 -> 炒鸡蛋 -> 炒番茄出汁 -> 混合装盘 -> 家人品尝
```

中文模式示例：

```text
15秒儿童亲子烹饪教学短片，可爱3D卡通风格，温馨明亮家庭厨房，严格沿用首帧中的家庭成员、厨房背景、番茄、鸡蛋和厨具，不新增人物，不改变人物外观。镜头固定围绕同一浅色木质操作台，动作按番茄炒蛋流程顺序推进，每段只表现一个主要动作：1俯拍食材，展示新鲜番茄和鸡蛋；2小女孩在水槽前清洗番茄，成人在旁微笑指导；3妈妈把鸡蛋打入碗中，小女孩双手扶碗观察；4小女孩用筷子轻轻搅拌冷鸡蛋液；5爸爸在砧板上安全切番茄，小女孩站在安全距离外观察，双手远离刀具；6爸爸操作炉具热锅炒蛋，孩子保持距离看鸡蛋变金黄；7妈妈把番茄倒入锅中翻炒出红色汤汁；8爸爸把鸡蛋回锅，妈妈轻轻翻拌，孩子递盘子；9近景装盘，番茄炒蛋颜色鲜亮；10家庭成员围在成品旁开心点头。画面明亮干净，动作简单清晰，手部自然，食材不变形，节奏平稳连续。不要出现任何文字、字幕、Logo、水印、品牌标识、乱码；不要出现儿童独自用刀、靠近明火、危险动作；不要出现脏乱厨房、暗黑氛围、恐怖元素、面部扭曲、手指畸形、身体比例错误、模糊、过曝、抖动、食材腐烂或错误食材。
```

英文模式仅在后续明确需要英文视频 prompt 时启用，结构与中文一致：

```text
A 15-second children's family cooking tutorial in a cute 3D cartoon style. Use the same family members, warm bright kitchen, tomatoes, eggs, and tools from the first frame. Do not add new people or change appearances. Keep the camera around one light wood kitchen counter. Show the tomato scrambled eggs workflow in order, one main action at a time: ingredient display, child washing tomatoes with adult guidance, mother cracking eggs, child gently stirring cold egg mixture, father safely cutting tomatoes while the child watches from a safe distance, adult cooking eggs, mother stir-frying tomatoes into red sauce, eggs mixed back in, plating, and family smiling beside the finished dish. No text, subtitles, logo, watermark, unsafe child actions, distorted hands or faces, blurry image, wrong or rotten ingredients.
```

Prompt 约束规则：

- 不在视频 prompt 中要求模型生成字幕或声音，线上版本不制作 TTS/配音后处理。
- 明确“只出现首帧中的人物，不新增人物”。
- 明确每个角色的职责，避免人物各忙各的。
- 动作必须按烹饪步骤顺序推进，不使用抽象描述。
- 镜头锚定同一个厨房操作台，减少场景切换导致的人物漂移。
- 每个镜头只表现一个主要动作，并显式写出儿童安全边界。
- 负面约束直接合并到同一条视频 prompt 中，限制文字、字幕、水印、危险动作、人物畸形和食材错误。

## 6. 质量验证

试运行返回视频后必须做以下记录：

- 视频 URL 是否返回。
- 视频文件是否可下载。
- 实际视频时长是否接近 `frames / 24`。
- 首帧人物数量是否符合剧情设定。
- 原始视频是否覆盖主要烹饪步骤。
- 人物脸部、手部是否明显变形。
- 人物动作是否按步骤推进，是否出现“各忙各的”。

## 7. 成本与缓存策略

每个菜谱默认只允许：

```text
1 次首帧图片生成 + 1 次视频生成
```

不再生成 3 张关键帧，也不做多段视频拼接。

缓存结构更新：

```ts
export interface RecipeVideoLocalCache {
  recipeId: string;
  recipeName: string;
  stepsHash: string;
  locale: 'zh' | 'en';
  provider: 'jimeng';
  imageModel: 'jimeng_i2i_v30';
  videoModel: 'jimeng_i2v_first_v30';
  firstFrameTaskId: string;
  firstFrameUrl: string;
  videoTaskId: string;
  status: 'running' | 'succeeded' | 'failed';
  videoUrl?: string;
  createdAt: string;
  expiresAt?: string;
}
```

缓存 key 保持版本化：

```text
murphy-cookbook.recipe-video-cache.v2
```
