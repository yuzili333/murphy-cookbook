# Murphy's Cookbook

Murphy's Cookbook is a kid-friendly AI cooking agent for elementary-school children and families. It turns text, voice, camera, and image inputs into confirmed ingredients, streams recipe recommendations, generates cooking steps on demand, supports bilingual learning, and matches reviewed cooking videos.
